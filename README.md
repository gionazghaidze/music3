# 🎧 Melomix — მუსიკების შემომთავაზებელი და ამრჩევი პლატფორმა (React Project)

**Melomix** არის თანამედროვე React აპლიკაცია, რომელიც მომხმარებელს სთავაზობს და ურჩევს საუკეთესო, პოპულარულ და მის განწყობაზე მორგებულ მუსიკალურ კომპოზიციებს.

---

## 📌 პროექტის მოთხოვნების შესრულება

| მოთხოვნა | შესრულების დეტალები |
| :--- | :--- |
| **კომპონენტებად დაყოფა** | პროექტი დაყოფილია 9 დამოუკიდებელ კომპონენტად, თითოეული ცალკე `.jsx` და `.css` ფაილში. |
| **Header Sign In & Log In** | Header-ის მარჯვენა მხარეს დამატებულია **Log In** და **Sign In** ღილაკები შესაბამისი ინტერაქტიული მოდალით (`AuthModal`). |
| **Props (მშობელი ➔ შვილი)** | მშობელი კომპონენტი (`App.jsx`) გადასცემს მონაცემებსა და callback ფუნქციებს შვილ კომპონენტებს. |
| **CSS დიზაინი** | თანამედროვე Dark Mode დიზაინი, Glassmorphism ეფექტები, ნეონის გრადიენტები და აუდიო ექვაილაიზერის ანიმაციები. |
| **გაფართოებული მუსიკების ბაზა** | 26 მრავალფეროვანი კომპოზიცია (ქართული და მსოფლიო ჰიტები, კლასიკა, როკი, ელექტრონული, ლო-ფაი). |
| **მასივები და `map()`** | მუსიკების ბაზა, განწყობების კატეგორიები და სტატისტიკა ინახება მასივებში და ეკრანზე გამოდის `.map()`-ით. |
| **`useState` და `useEffect`** | გამოიყენება მონაცემების, ფლეიერის, ფილტრების, საძიებო ველისა და რჩეულების სამართავად. |
| **API სერვისი** | `services/musicApi.js` ახორციელებს ასინქრონულ მოთხოვნებს (Promise, async/await, timeout). |
| **Router / ნავიგაცია** | რეალიზებულია მრავალგვერდიანი SPA ნავიგაცია (მთავარი, რეკომენდატორი, რჩეულები, სტატისტიკა) Hash-ის მხარდაჭერით. |

## 🚀 როგორ გავუშვათ პროექტი

### ვარიანტი 1: მომენტალური გაშვება (სწრაფი)
თუ კომპიუტერზე არ გაქვთ დაყენებული Node.js:
1. გახსენით პროექტის საქაღალდე.
2. უბრალოდ ორჯერ დააკლიკეთ ფაილს **`start.bat`** (ან პირდაპირ გახსენით **`preview.html`** ნებისმიერ ბრაუზერში: Chrome, Edge, Opera).
3. პროექტი მომენტალურად გაიხსნება მისამართზე `http://localhost:8000/preview.html` სრული ფუნქციონალითა და დიზაინით!

### ვარიანტი 2: სტანდარტული Vite Development Server
თუ გაქვთ Node.js:
```bash
# 1. დააინსტალირეთ პაკეტები
npm install

# 2. გაუშვით დეველოპერ სერვერი
npm run dev
```
ბრაუზერი ავტომატურად გაიხსნება მისამართზე `http://localhost:3000`.
